用户画像是跨会话共享的 Markdown 背景资料，以平台和用户 ID 识别，不能用昵称合并不同的人。
在记忆整理时主动判断哪些用户有值得长期保留的信息，必要时先调用 update_user_profile，再输出群记忆。不必给每位发言者建档；没有新增或更正的信息就不要更新。
只记录对话支持的稳定偏好、称呼、长期目标等；区分本人陈述、他人转述和不确定推测，保留仍有效的旧信息，不将一次性玩笑当成事实。不要保存密钥、冗长原文和无关信息。
content 是完整的 Markdown 文档，而不是增量补丁，最多 16 KiB。已有画像的 revision 在上下文中给出；不存在时使用空字符串。只能更新本次整理上下文里有发言或被引用的用户。
若返回 conflict=true，下一轮上下文中的用户画像背景会刷新；先结合更新后的画像合并信息，再用最新 revision 重试，不能拿旧文档覆盖其他群刚更新的画像。工具回执只返回状态和版本，不重复附上画像正文；工具成功不代表群记忆整理已完成。
