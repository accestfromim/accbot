# AI 插件

默认插件位于 `plugins/ai/`，使用与第三方插件相同的事件、工具、配置页和生命周期接口。

| 插件 | 功能 |
| --- | --- |
| `ai.chat` | 群聊参与、上下文、工具循环、会话、记忆及私聊通道 |
| `ai.tools` | 搜索、网页读取、下载、图片和文件发送、进度消息 |

两者默认不激活。`ai.chat` 声明依赖 `ai.tools`，启用时需一并选择。安装依赖使用 `uv sync --extra ai`，启动使用 `uv run --extra ai accbot serve`。

## 配置

在插件页面点击「AI · 群聊与会话」的配置按钮，选择默认模型、人格卡和聊天/主人/记忆整理提示词卡，并填写允许参与的群。一个群配置由连接 ID 和群 ID 定位；未启用的群不进入聊天观察和记忆。

人格卡和提示词由框架共享目录维护。默认人格中的 `[机器人名称]` 是供使用者编辑的文字占位符。机器人账号从入站事件的 `connection.bot` 获取，以独立 system 资料加入模型上下文；账号身份不依赖人格名称。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `initial_probability` | 0.01 | 无活跃会话时的普通参与概率 |
| `busy_probability` | 0.30 | 无活跃会话时的高频参与概率 |
| `active_probability` | 0.20 | 活跃会话中的普通参与概率 |
| `active_busy_probability` | 0.20 | 活跃会话中的高频参与概率 |
| `busy_seconds` | 60 | 判定消息高频的时间窗 |
| `cooldown_seconds` | 5 | 概率触发的冷却时间 |
| `idle_seconds` | 180 | 最后一次唤醒后的会话空闲期限 |
| `context_budget` | 200000 | 上下文预算，使用保守估算，非供应商精确 token 数 |
| `output_reserve` | 16384 | 输出预留预算 |
| `max_tool_rounds` | 32 | 单轮对话的模型调用次数上限 |

插件观察最近 15 条消息；新消息到来时，若此前 15 条均在高频时间窗内，则使用高频概率。@ 机器人可以绕过概率和冷却；群配置中的 `mention_users` 可限制允许 @ 唤醒的用户，留空表示该群所有成员。

## 会话与模型上下文

同一群的模型轮次按 FIFO 执行，不同群可以并发。发送回复时使用触发该轮的连接地址。群友身份、时间和引用填写到 ModelItem，由框架合并相邻 user 消息；助手回复、工具调用、工具结果和供应商续接信息保持顺序，详见 [模型上下文](model-context.md)。

人格、提示词、机器人账号、长期记忆和工具 Schema 都计入上下文预算。预算以 UTF-8 字节进行保守估算，每张图像按 8192 计算；裁剪只移除完整历史轮次，保留当前任务和必要前缀。

工具可以并行执行。模型不需要发言时应单独、无参数调用 `stay_silent`。查看消息图片时按需载入并压缩，图像仅附在当前轮次中，不把 Base64 写入长期记忆。引用优先读取本地观察记录，缺少原文时通过消息查询接口补全，只展开一层。

## 记忆与定时整理

记忆主键是稳定业务身份 `MemoryKey`：QQ 使用平台、会话类型和群号/用户号；其他平台还包含稳定租户作用域。连接 ID、插件激活 ID 和运行期会话 ID 不进入 QQ 记忆主键，因此重启、重载或更换连接后仍可接续同一群记忆。

```text
.accbot/data/plugins/
├─ ai.chat/
│  ├─ config/settings.json
│  └─ memory/<MemoryKey 的 SHA-256 前 24 位>/
│     ├─ memory.json       # 稳定身份、路由提示、记忆和提交标记
│     └─ pending.json      # 待整理轮次及未消费消息
└─ ai.tools/downloads/    # 工具下载目录
```

记忆正文包含 `version`、`summary`、`members`、`facts` 和 `open_tasks`，上限为 64 KiB。成员结构中的 `qq` 字段保存用户 ID。记忆正文与提交标记原子保存，避免重复整理已提交的轮次。

实际唤醒时，消息处理器只取消并重设当前群的 `SummarizeMemory` 定时事件，字段携带稳定记忆身份和校验标记。普通消息未唤醒时不会延后期限。到期后，订阅处理器校验标记，将整理排入该群队列，等待已接受的轮次完成；无需遍历所有群。

整理失败按 1、2、4、8、15 分钟安排重试，也会在下一轮对话前尝试。重启恢复待整理记录，不重放工具；结果不完整的工具调用标为结果未知。损坏的文件报错并保留，不用空记忆覆盖。

修改配置或停用插件时保留待整理日志。插件最多等待当前聊天任务 5 秒，再取消未完成的聊天任务；框架已接受的后台工具仍可自然完成。旧激活的回复和定时事件不会投递给新实例。

## 私聊与工具范围

- 普通私聊由白名单筛选，需 @ 唤醒，采用无状态对话，不建立长期记忆。
- 主人私聊由连接 ID 和用户 ID 筛选，逐条唤醒，维护独立记忆。
- 文件读写与 Shell 默认关闭，仅在配置主人并开启控制工具后提供给主人私聊。执行时再次核验真实入站消息的发送者与会话。

三类消息使用独立的 `@on_message` 订阅。框架提供通用身份过滤器，主人角色和工具范围由插件实现。普通群聊不会获得文件控制和 Shell 工具，也不会注入这些工具的提示词。

网络工具读取公开 HTTP(S) 地址，逐跳验证重定向，下载上限为 50 MiB。普通文件发送只能读取下载目录中的文件。图片使用内联数据发送；群文件上传要求协议端支持相应扩展，并能访问下载文件路径。网页搜索使用 Bing 和 DuckDuckGo 的 HTML 页面，外部站点的访问限制或结构变化会导致失败或空结果。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `chat/plugin.py` | 装饰器订阅、工具选择、配置更新 |
| `chat/sessions.py` | 消息观察、队列、会话、定时整理与恢复 |
| `chat/agent.py` | 模型与工具循环、上下文前缀、记忆整理调用 |
| `chat/context.py` | 结构化消息、引用及完整轮次预算 |
| `chat/identity.py`、`chat/memory.py` | 稳定记忆身份及持久化 |
| `chat/settings.py`、`chat/frontend/` | 插件配置及页面 |
| `tools/plugin.py` | 网络与消息工具声明及公开接口 |
